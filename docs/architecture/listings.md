# Architecture - where Evermist is listed

The sites that list Evermist, what each carries, and what a release asks of them, in the present tense.

| Where | What it carries | Account |
|---|---|---|
| GitHub, `Hinnful/Evermist` | The README, releases, description and topics | The repo owner |
| AlternativeTo | The description, tags, platforms, icon, five screenshots, and five apps it is an alternative to | The repo owner's AlternativeTo account |
| itch.io, `hinnful.itch.io/evermist` | The description, tags, cover, five screenshots, and one download link to GitHub's latest release | The repo owner's itch.io account |

- **A release needs nothing on any listing.** Every download link points at GitHub.
- **A notable feature updates the descriptions.** Each listing's text follows the README's
  opening; when the README's first paragraphs change, the listings change with it.
- **New screenshots come from the README's animations**, one still frame each, PNG.
- Why each listing has its shape is in [decisions/discoverability.md](../decisions/discoverability.md).
