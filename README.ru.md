Evermist сделан для мастеров, которые водят НРИ за столом, вживую. Карта выводится на телевизор под туманом войны, и туман рассеивается по мере того, как группа исследует локацию. Приложение бесплатное, и останется таким навсегда

У каждой обведённой комнаты есть название и заметки. Разметьте подземелье заранее, и когда группа выбьет эту дверь, название комнаты и заметки к ней уже будут на ноутбуке

> **Это не VTT.** Ни токенов, ни инициативы, ни кубиков, ни листов персонажа. Игру мастер ведёт так же, как вёл раньше. Evermist отвечает за карту и за то, что о ней знает группа

![Снятие тумана в окне игрока](assets/reveal.gif)

## Перед игрой

### Комнаты с заметками

Обведите комнату, и её закроет туман. Клик по комнате открывает её название, заметки и то, насколько она спрятана. Комната - это что угодно, что обведено, терраса или отрезок коридора тоже

Названия комнат отображаются на карте мастера, так что даже на этаже трёхнедельной давности сразу понятно, где что. Всё сохраняется автоматически, наполовину пройденное подземелье таким и останется до следующей игры

### Если игра идёт по готовому модулю

Загрузите модуль в `.txt` или `.pdf`, и Evermist вычитает из него все пронумерованные локации: `K12. Церковь` и остальные восемьдесят девять. Поиск по ним работает прямо из поля названия любой комнаты: начните писать «церковь», выберите нужную, и название с заметками подставятся сами

![Название и заметки комнаты подставляются из текста модуля](assets/module-text.gif)

### Если всё хоумбрю

Импортировать нечего, так что название и заметки вписываются руками. Комнаты могут стоять пустыми сколько угодно, так что можно обвести весь этаж за один раз, а описать его потом

### Если к карте есть план этажа

Если карты делаются в редакторе, он может уметь экспортировать стены вместе с картинкой. Ищите «Universal VTT» в настройках экспорта - рядом с картой сохранится файл `.dd2vtt`. Загрузите карту, у которой такой файл лежит в той же папке, и Evermist предложит обвести все комнаты сам

Пещеры автоматически не обводятся. Здания внутри пещеры появятся, а саму пещеру придётся обвести руками

![Все комнаты обведены с плана этажа одним нажатием](assets/draw-rooms.gif)

## За столом

### Сетап

Есть окно мастера со всем управлением и чистое окно игрока, где только карта, туман и сетка. Заметки остаются в окне мастера

1. Подключите телевизор кабелем HDMI и включите расширение рабочего стола. Ничего не транслируется, так что телевизор не отстаёт
2. Запустите Evermist и загрузите карту. Туман лучше настроить сразу, до того как что-то попадёт на телевизор
3. Откройте окно игрока во вкладке Player, перетащите его на телевизор и нажмите Fullscreen
4. Играйте. Открывайте комнаты по мере того, как группа их находит

![Окно мастера](assets/dm-window.png)

### Туман

Туман плывёт и медленно меняет форму, так что похож на погоду над картой

У каждой комнаты есть режим: Revealed, Shrouded или Half-shrouded. Shrouded - то, что группа ещё не нашла, Revealed - где она стоит сейчас, Half-shrouded - там, где она уже была, но сейчас её там нет

Любую комнату можно передвинуть, переделать или удалить в любой момент. Цвет тумана задаётся отдельно для каждой сцены: синий для подземелья, зелёный для болота, красный когда всё пошло не так

![Рисование областей показа и скрытия](assets/tools.gif)

### Анимированные карты

Загрузите MP4 или WebM, и вода будет переливаться, а факелы мерцать везде, где группа сняла туман

![Анимированная карта под туманом](assets/animated-map.gif)

## Всё остальное

- Ручной режим (Manual): следующее открытие можно подготовить втайне и выпустить одной кнопкой, когда группа действительно откроет дверь
- Миникарта справа показывает, какая часть карты сейчас на телевизоре. Потяните её, чтобы сдвинуть кадр
- Сетка квадратами или гексами. Размер, смещение, цвет и прозрачность - весь базовый набор
- Смена карт по ходу игры: туман закрывает переход, и экран не гаснет
- Карта 10000×6000 двигается и масштабируется без лагов
- Экспорт любого набора сцен в один `.zip`, вместе с файлами карт, и восстановление на другом компьютере
- Притягивание углов комнат к сетке и выравнивание стен, если это нужно

Клавиша `?` в окне мастера показывает список горячих клавиш

## Что нужно

Карта. Подойдёт любой файл с картинкой или видео

Остальное необязательно и просто ускоряет подготовку:

| Что есть | Что это даёт |
|---|---|
| Любая карта PNG или JPG | Туман, комнаты, заметки, сетка, оба экрана. Всё целиком |
| Готовый модуль в `.txt` или `.pdf` | Названия и заметки подставляются из книги |
| Карта в MP4 или WebM | Карта анимируется |
| План `.dd2vtt` рядом с картой | Все комнаты обведены сами, кроме пещер |

Комнаты, обведённые руками, работают точно так же, как обведённые автоматически

## Скачать

Свежую версию для вашей системы берите в [**Releases**](../../releases/latest):

| Система | Файл | Примечания |
|--------|------|-------|
| Windows | `Evermist-<версия>.exe` | Портативный, ставить не нужно, просто запускается |
| macOS | `Evermist-<версия>.dmg` | Универсальный (Intel и Apple Silicon) |
| Linux | `Evermist-<версия>.AppImage` | Сделать файл исполняемым и запустить |

Evermist не подписан цифровой подписью (сертификаты стоят денег), поэтому при первом запуске система покажет разовое предупреждение безопасности. Оно безобидное

<details>
<summary>Как пройти предупреждение при первом запуске</summary>

- **Windows:** если появилось «Система Windows защитила ваш компьютер», нужно нажать «Подробнее», затем «Выполнить в любом случае»
- **macOS:** если появилось «Программу Evermist нельзя открыть, так как Apple не может её проверить…», кликнуть по приложению правой кнопкой мыши, выбрать «Открыть», а потом ещё раз «Открыть» в диалоге. (При обычном двойном клике этой кнопки в первый раз не будет.)
- **Linux:** нужно сделать AppImage исполняемым (`chmod +x Evermist-*.AppImage` или «Свойства → Права → Разрешить выполнение файла как программы») и запустить как обычно

Система запомнит выбор, так что это только в первый раз

## Ничего не уходит с компьютера

Ни аккаунта, ни облака, ни сетевого трафика. Evermist работает с выключенным wifi

Карты и сцены лежат на диске. PDF модулей читаются в отдельном изолированном процессе, у которого нет доступа к файлам

## Запуск из исходников

Шага сборки нет. Это обычный JavaScript в оболочке Electron

```bash
npm install     # один раз, после клонирования
npm start       # запустить приложение
```

Собрать установщик под текущую платформу:

```bash
npm run build         # Windows portable .exe
npm run build:mac     # macOS .dmg
npm run build:linux   # Linux AppImage
```

Сборки под все три платформы GitHub Actions делает сам при пуше тега `v*` (см. файл [`.github/workflows/release.yml`](.github/workflows/release.yml))
